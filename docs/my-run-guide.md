\# My Run Guide



\## Prerequisites

\- Git

\- Python 3 (check with `python3 --version`)

\- A clone of this repository



\## Run the demo

From the repository root, run:



&#x20;   python3 run.py demo



\## What the demo does

It runs the library application demo: it sets up a small catalog and members, then shows borrowing, returning and searching for books, and prints the results to the console.
